# Knowledge: 06W Missing Business Rule Framework

## Type
Analysis Framework

## Content

06W dùng để tìm business rule chưa được source xác định.

| Dimension | Câu hỏi | Focus |
|---|---|---|
| **What if — Input** | Input bất thường thì sao? | Invalid, empty, malformed input |
| **What if — State** | State bất thường thì sao? | Expired, cancelled, already processed |
| **What if — Data** | Data bất thường thì sao? | 0, âm, null, duplicate, boundary |
| **What when — Timing** | Xảy ra theo thời gian thì sao? | Timeout, expiry, concurrency, retry |
| **Who else — Actor** | Actor khác thì sao? | Admin, system, external service, job |
| **What happens after — Post-condition** | Sau action thì sao? | State, data, side effect |

## Rule

Chỉ xem là Missing Rule khi source chưa xác định behavior cần thiết.

Không được tạo Missing Rule bằng cách suy diễn tùy tiện hoặc lặp lại business rule đã có.
